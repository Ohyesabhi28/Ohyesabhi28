### [NeuroTidy — AI Code Review Platform](https://github.com/Ohyesabhi28/ERROR-108-AWS-Hackathon)

A serverless GitHub PR reviewer that catches ML-specific bugs that regular linters miss.

- **17+ static analysis rules** for Python/ML code: missing gradient resets, wrong loss functions, and more
- Automated PR review comments powered by **Amazon Bedrock**
- Fully serverless on **AWS Lambda + API Gateway**

`Python` `AWS Lambda` `Amazon Bedrock` `API Gateway` `GitHub API`
